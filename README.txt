Folder maskot BahasaKoe

Saat ini semua posisi maskot memakai PLACEHOLDER. Untuk memasang maskot asli:

1. Simpan gambar di folder ini (persegi, latar transparan, SVG atau PNG):
     wave.svg    - menyapa      (Home, Lesson Intro)
     think.svg   - berpikir     (Culture Moment)
     cheer.svg   - merayakan    (Lesson Complete)
     happy.svg   - senang       (belum dipakai; kandidat feedback "Benar!")
     gentle.svg  - menyemangati (belum dipakai; kandidat feedback "Belum tepat")
2. Buka js/ui/mascot.js, ubah   USE_ASSETS = false   menjadi   true
   (jika memakai PNG, ubah juga MASCOT_EXT menjadi 'png').

Mood yang berkasnya belum ada otomatis tetap tampil sebagai placeholder.
Ukuran tampil: kecil 56px, sedang 88px, besar 120px (di layar mobile).
